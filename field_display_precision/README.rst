This module allows administrators to define the decimal precision of
float fields based on the model. PDF reports generated from these models
will also reflect the specified decimal precision.

Note: It only changes the presentation in the user interface and does
not alter the data stored in the database.

Use Cases / Context
===================

In the Odoo standard, the number of decimal places for float fields is
determined by the Decimal Accuracy setting and is shared across all
models. However, in some cases, users may want to define different
decimal precision values for specific models.

Known issues / Roadmap
======================

The design approach used in this module is not ideal. Currently, decimal
precision can only be defined at the model level, whereas it should
ideally be configurable based on the unit of measure (UoM). This
limitation may be addressed in a future update.
